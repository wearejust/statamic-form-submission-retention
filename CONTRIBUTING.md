# How to Contribute to Statamic

Thank you for taking the time to contribute!

This quick guide explains how you can contribute to this addon.

## What You Should Know Before Contributing

### Reporting issues

Before creating a new issue, please search through the [open issues](https://github.com/wearejust/statamic-form-submission-retention/issues) to see if it has already been opened.

If you find a similar issue, leave a comment if you have relevant information to add.

If there is no similar issue yet, feel free to create one! Please include a clear description of the issue, and provide and as much relevant information as possible.

### Pull Requests

Pull requests should clearly describe the problem and solution. Please be sure to include the relevant issue number if there is one.

Thanks again for helping us improve!
